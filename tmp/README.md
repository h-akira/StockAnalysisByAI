# tmp/

**今後見返すかもしれない作業ファイルの一時置き場。**

git 管理下に置く (履歴を保つ)。役割を終えたら [`old/`](../old/README.md) へ移すか削除する。

## ここに置くもの

- 設計議論の中で生まれた一時メモ
- ある決定に至った経緯の記録（後でレビュー対象になり得る）
- 検討中のラフメモ

## ここに置かないもの

- 「現在の正」となる設計ドキュメント → ルート / `references/` / Skill 配下の `docs/` 等
- 完全に役目を終えたアーカイブ → [`old/`](../old/README.md)
- バグや改善の追跡 → `bugs/` / `enhancements/`
- 機密情報や API キー → どこにも commit しない
- 5 MB 級のバイナリ → 添付しない

## AI への指示

`tmp/` 内のファイルは **タスク中に明示的に参照を求められた場合のみ読む**。
通常の実装作業では参照する必要はない（コンテキスト汚染を避ける）。
