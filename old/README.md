# old/

**説明済みや古い認識のアーカイブ置き場。**

git 管理下に置く (履歴を保つ)。「現在の正」ではないが、過去の判断の根拠を辿るのに必要なファイルを格納する。

## ここに置くもの

- 設計が変わって役割を終えたが、変更前の根拠として残したいドキュメント
- リファクタや方針転換で削除した古いコード断片（必要に応じて）
- 一度公開した README や仕様書の旧版

## ここに置かないもの

- 「現在の正」となる設計ドキュメント → ルート / `references/` / Skill 配下の `docs/` 等
- 検討中・作業中のメモ → [`tmp/`](../tmp/README.md)
- バグや改善の追跡 → `bugs/` / `enhancements/`
- 機密情報や API キー → どこにも commit しない

## AI への指示

`old/` 内のファイルは **タスク中に明示的に参照を求められた場合のみ読む**。
通常の実装作業では古い認識に引きずられないよう参照しない（コンテキスト汚染を避ける）。
